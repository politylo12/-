# Тетріс з AI (Штучним Інтелектом)

Цей проєкт створений за аналогією до проєкту **Flappy Bird з AI (М2У6)** з використанням **Pygame**, **pandas**, **scikit-learn (DecisionTreeClassifier)** та **joblib**.

---

## 📁 Структура проєкту

* **`collect_data.py`** — модуль зі збирачем даних (`DataCollector`), який записує стани гри та якість ходів у CSV-файл `tetris_data.csv`.
* **`model_trainer.py`** — скрипт для навчання моделі машинного навчання (Дерева рішень `DecisionTreeClassifier`), оцінки точності та збереження у файл `tetris_model.joblib`.
* **`main.py`** — основна гра Тетріс на Pygame з двома режимами: **HUMAN** (гравець) та **AI** (штучний інтелект).
* **`tetris_data.csv`** — датасет із записами станів і дій.
* **`tetris_model.joblib`** — навчена модель дерева рішень.

---

## 🎮 Керування у грі (`main.py`)

* **`M`** — перемикання режиму керування між **HUMAN** (гравець) та **AI** (штучний інтелект).
* **Стрілка вліво `←`** — рух фігури вліво.
* **Стрілка вправо `→`** — рух фігури вправо.
* **Стрілка вгору `↑`** — обертання фігури.
* **Стрілка вниз `↓`** — прискорене падіння (Soft drop).
* **Пробіл `Space`** — миттєве падіння на дно (Hard drop).
* **`R`** — перезапуск гри після Game Over.

---

## ⚡ Підвищена складність (Hard Mode після 250 очок)

Як тільки ваш рахунок досягає або перевищує **250 очок**, гра автоматично активує режим підвищеної складності:
1. **Блоки-перешкоди на полі:** після кожного приземлення фігури на полі випадково з'являється блок-перешкода (сірий із червоним маркуванням `X`), який створює нерівності та отвори. Їх можна знищувати, заповнюючи повні горизонтальні лінії.
2. **Рандомні нестандартні фігури:** до пулу стандартних 7 фігур додаються нові форми (одиночний блок `DOT`, куточок `CORNER`, хрестик `PLUS`, 3-блочна лінія `BAR3`).
3. **Статус у сайдбарі:** індикатор праворуч змінюється на `Difficulty: HARD [250+]`.

---

## 🧠 Як працює AI

1. Для кожної нової фігури AI аналізує всі можливі варіанти розміщення (обертання та стовпчики).
2. Для кожного варіанту обчислюються ключові ознаки поля:
   - `lines_cleared` — кількість очищених ліній
   - `holes` — кількість утворених отворів/дірок
   - `bumpiness` — перепади висот між стовпчиками
   - `aggregate_height` — загальна сумарна висота
   - `max_height` — максимальна висота стовпчика
   - `landing_height` — висота приземлення фігури
3. Модель машинного навчання прогнозує якість ходу (`good` або `bad`).
4. AI обирає найкращу позицію і плавно переміщує туди фігуру на екрані.

---

## 🚀 Як запускати

1. **Запуск гри:**
   ```bash
   python main.py
   ```
   Натисніть **`M`**, щоб спостерігати за грою AI або грати самостійно.

2. **Навчання моделі:**
   ```bash
   python model_trainer.py
   ```
   Скрипт зчитає `tetris_data.csv`, навчить нове Дерево рішень, виведе точність та збереже `tetris_model.joblib`.

3. **Генерація нових даних (за потреби):**
   ```bash
   python collect_data.py
   ```
